## ✨ Features

- 🌌 **Cinematic Canvas Animations:** Custom-built JavaScript background rendering slow-drifting, ambient glowing orbs.
- 🎨 **Deep Violet Aesthetic:** A highly professional, corporate-grade deep purple and onyx color palette.
- 🧩 **Dynamic Component Loading:** Content sections (Hero, About, Skills, Projects, etc.) are modularized and injected dynamically via JS `fetch` API for a seamless SPA-like feel without a heavy framework.
- 📱 **Fully Responsive:** Meticulously crafted CSS media queries ensure the layout, typography, and interactive elements scale perfectly from ultra-wide 4K monitors down to mobile screens.
- 🖱️ **Custom Interactive Cursor:** A bespoke trailing ring cursor that interacts with the user's mouse movements on desktop.
- 🚀 **Performance Optimized:** No heavy libraries or frameworks. Pure, vanilla HTML, CSS, and JS for maximum speed.

## 🛠️ Tech Stack

This project is built strictly with core web technologies to showcase fundamental frontend mastery:

* **HTML5:** Semantic structuring and modular component architecture.
* **CSS3:** Advanced animations (`@keyframes`), CSS variables for dynamic theming, CSS Grid & Flexbox, and complex gradients.
* **Vanilla JavaScript (ES6+):** Intersection Observers for scroll animations, Canvas API for the background, and async/await data fetching.

## 🚀 Getting Started

If you want to run this project locally to explore the code or customize it for yourself:

### Prerequisites
You only need a modern web browser and a local development server (due to CORS policies with the JS `fetch` API used for modular HTML loading).

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ea-arnob-07/Arnob-Portfolio.git
   cd Arnob-Portfolio
   ```

2. **Run a local server**
   You can use the Live Server extension in VS Code, or Python's built-in HTTP server:
   ```bash
   # Python 3
   python -m http.server 8000
   ```

3. **Open your browser**
   Navigate to `http://localhost:8000` to view the site!
